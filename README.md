# 💒 Shubh Vivah — Wedding Event Management Website

A responsive Indian Wedding Planning website built with HTML, CSS, and JavaScript.
*"Plan Your Wedding With Us — ShubhVivah Is An Indian Wedding Planning Website"*

## 🌐 Live Sections
- **Home** — Full-screen hero banner with vendor type and city search dropdowns
- **Services** — 8 wedding services: Invitation, Photography, Beauty & Makeup, 
  Wedding Flowers, Cake, Music Band, Catering, Jewellery
- **Featured Vendors** — 8 vendor cards with ratings, pricing (₹), and hover zoom effect
- **Venues** — 6 Indian city venues: Delhi, Mumbai, Bangalore, Pune, Goa, Uttarakhand
  with hover overlay effect
- **E-Invites** — Gallery of 15 wedding invitation card designs
- **Contact/Footer** — Newsletter subscription, social media links, location links

## ✨ Features
- Fixed navigation header with smooth scroll behaviour
- Full-screen hero with CSS gradient overlay and background image
- Vendor search with dropdown filters — Vendor Type and City
- Vendor cards with star ratings and pricing in Indian Rupees (₹)
- Venue cards with CSS hover overlay reveal animation (`opacity + scale`)
- Invitation card gallery with `translateY` hover lift effect
- Social media icons with `rotate(360deg)` hover spin animation
- Custom scrollbar styling using `::-webkit-scrollbar`
- CSS variables (`--clr1` to `--clr6`) for consistent theming
- Google Fonts — Charm + Acme + Rubik Moonrocks
- Font Awesome 6.5.2 icons throughout
- Fully responsive using CSS Flexbox and `flex-wrap`

## 🛠️ Tech Stack
- HTML5 — semantic structure with 6 sections
- CSS3 — variables, flexbox, transitions, keyframes, overlays
- Font Awesome 6.5.2 — icons for services and social media
- Google Fonts — Charm, Acme, Rubik Moonrocks

## 📁 Files
- `index.html` — complete HTML structure
- `styleunique.css` — all custom styles, animations and responsive layout

## 🚀 How to Run
Open `index.html` in any browser — no installation needed!
